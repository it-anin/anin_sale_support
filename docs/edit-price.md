# Edit Price

หน้าเปรียบเทียบทุนและคำนวณราคาใหม่ตาม `PROJECT-OVERVIEW.md` สำหรับโปรไฟล์ `PURCHASING` เท่านั้น ปุ่ม **Edit Price** แทน **Label** ในตำแหน่งเดิมบนทุกหน้า รหัสอื่นยังเห็น Label และใช้สิทธิ์เดิม หากออกจากระบบขณะอยู่หน้า Edit Price แล้วล็อกอินรหัสอื่น ระบบจะกลับไปหน้าที่รหัสนั้นเปิดได้

## การใช้งาน

1. เปิด Edit Price แล้วเลือก Product Master กับ Promaxx รองรับ `.xlsx`, `.xls`, `.csv` อ่านเฉพาะชีตแรก และใช้แถวแรกเป็นหัวตาราง
2. กด Compare Prices เพื่อคำนวณทุกหน่วยของ SKU ใช้ตัวกรอง ไม่ตรง / ทั้งหมด / ตรง / ไม่พบ และค้นหาด้วย SKU ชื่อสินค้า หรือหน่วย
3. เลือกดูราคาได้ไม่เกิน 10 แถว และเลือกระดับ 0/1/4/5 ใน Selected Results ช่อง “ตรวจแล้ว” เก็บใน localStorage แยกจากการเลือกแถว
4. แท็บ Export ส่งออก TXT ตามระดับราคา หน่วยฐาน หรือหน่วยที่เลือก และรายงาน Excel พร้อมราคาเก่า/ใหม่

ไฟล์และผลคำนวณอยู่ในหน่วยความจำของหน้า เมื่อเปลี่ยนหน้า/รีเฟรชให้เลือกไฟล์ใหม่ เก็บถาวรเฉพาะ checklist ด้วย key `price-compare-row-checklist` ไม่เพิ่มตารางหรือเขียนข้อมูลราคาใน Supabase

## ข้อมูลและสูตร

| ไฟล์ | คอลัมน์ |
| --- | --- |
| Product Master | A: SKU, B: ชื่อ, C: หน่วยฐาน, J: หน่วยทุนใหม่, K: ทุนใหม่ |
| Promaxx | B: SKU, E: หน่วย, F: ระดับราคา, G: ราคาเก่าระดับ 0, H: ราคาเก่าระดับ 1/5 หรือทุนเก่าระดับ 4 |

ทุนใหม่ของหน่วย J ใช้ K โดยตรง หน่วยอื่นใช้ `(ทุนใหม่ K / ทุนเก่าของหน่วย J) × ทุนเก่าของหน่วยนั้น` ราคาขายใหม่ระดับ 0/1/5 เท่ากับ `(ทุนใหม่ของหน่วย / ทุนเก่าของหน่วย) × ราคาขายเก่าของระดับ` ปัดเป็นจำนวนเต็มด้วย `Math.round`

ค่าว่าง ตัวหารศูนย์ และผลที่ไม่ใช่จำนวนจำกัดแสดง `-` ไม่เดาตัวเลขแทน หากไม่พบหน่วย J จะเพิ่มแถวนั้นให้พร้อมทุน K ส่วนหน่วยอื่นที่คำนวณไม่ได้จะแสดง `-` Product Master ต้องมีทุนใหม่หนึ่งแถวต่อ SKU หากซ้ำจะแสดงข้อผิดพลาดก่อนสร้างผลลัพธ์

สถานะไม่ตรงคิดรวมทั้ง SKU เมื่อมีราคา 0/1/5 อย่างน้อยหนึ่งหน่วยต่างกันเกิน 0.001 ดังนั้นจำนวน Matched บนหน้าจอคือจำนวน SKU ที่พบและราคาไม่ต่างกัน

## ส่งออก

ทุกไฟล์ใช้แถวตามตัวกรองและคำค้นที่เห็นในแท็บ Export การเลือกแถวและ checklist ไม่จำกัดการส่งออก TXT ใช้เฉพาะแถวที่ทุนใหม่มากกว่าทุนเก่าและมีราคาของระดับนั้น ระดับ 4 ใช้ทุนใหม่ Excel รวมทุกแถวตามตัวกรอง รวมรายการทุนลดลงและไม่พบ SKU

TXT ใช้ UTF-8 BOM, CRLF และ `SKU<TAB>ราคา<TAB>ระดับ` ราคามีคอมมาหลักพันและทศนิยมสองตำแหน่ง ชื่อไฟล์ `ราคาระดับ X.txt`, `BASE_UNIT_ราคาระดับ X.txt` หรือ `<หน่วย>_ราคาระดับ X.txt` รายงาน Excel ชื่อ `Price_Comparison_Report.xlsx` มีชีตเดียว

## โค้ดและการตรวจสอบ

- `editprice/engine.ts`: จับคู่ คำนวณ กรอง และสร้างเนื้อหาส่งออก
- `editprice/EditPricePage.tsx` / `.css`: อัปโหลด ตารางแบบแสดงเฉพาะแถวที่มองเห็น และดาวน์โหลด
- `pageAccess.tsx`: ปุ่มแทน Label ผ่าน `PurchasingNavigationContext`
- `App.tsx`: ให้สิทธิ์ `editprice` และ mount หน้าเฉพาะ `PURCHASING` โดยไม่พึ่งค่าตั้งค่ากลางของหน้าอื่น
- `npm run test:edit-price`: ทดสอบสูตร กรณีข้อมูลขาด รูปแบบส่งออก และปุ่มนำทาง
- `npm run build`: ตรวจ TypeScript และ production build
