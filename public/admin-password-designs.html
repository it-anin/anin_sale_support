Admin Password Modal — 10 แบบ

ดีไซน์ใหม่สำหรับหน้าใส่ "รหัส admin" (ปุ่มเฟือง ⚙️ ตั้งค่าเปิด/ปิดหน้า) — ของเดิมคือ label + ช่องรหัส + ปุ่ม "ปลดล็อก 🔓" เรียบๆ
ทุกแบบใช้ label/placeholder/ปุ่มข้อความเดิม เปลี่ยนแค่ดีไซน์ภาพ (ไอคอน/เลย์เอาต์/สี) ให้ยังทำงานแบบเดิม (พิมพ์รหัส → กด/enter → ปลดล็อก)
บอกเลขแบบที่ชอบมาได้เลยครับ ผมจะใส่แทนของเดิมใน App.tsx

หมายเหตุ: แพทเทิร์นนี้ใช้ซ้ำใน admin unlock อีก 3 จุดของแอป (ฉลากยา, เบิกด่วน, admin panel หลัก) — ถ้าชอบแบบไหนบอกได้ว่าอยากใช้เฉพาะจุดนี้ หรือเปลี่ยนให้เหมือนกันทั้งแอปเลย
แบบ 10 (Segmented) เป็นแค่ภาพตกแต่งอินพุตเดียวให้ดูเหมือนช่อง PIN เท่านั้น ตัวข้อมูลจริงยังเป็น input รหัสผ่านช่องเดียวเหมือนเดิม ไม่ได้เปลี่ยนพฤติกรรมการพิมพ์
