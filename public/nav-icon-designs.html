Page Nav Icon — 20 แบบไม่มีสี

ปุ่มนำทาง .page-nav-card ในแถบ hero ทุกหน้า ปัจจุบัน .page-nav-icon เป็น emoji สี
ทุกแบบด้านล่างใช้ สีเดียวตามปุ่ม (currentColor) → ขาวบนพื้นฟ้า และเปลี่ยนเป็น #2d6cad อัตโนมัติตอน hover/active
คลิกปุ่มไหนก็ได้ เพื่อดูสถานะ active · เอาเมาส์ชี้เพื่อดู hover · บอกเลขแบบที่ชอบได้เลยครับ

แบบ 1–10, 16–20 = เปลี่ยนเป็น inline SVG (แก้ PAGE_NAV ใน pageAccess.tsx ให้เก็บ SVG แทน emoji) — สีตามปุ่มอัตโนมัติ คมชัดทุกความละเอียด
แบบ 11–13 = เก็บ emoji เดิมไว้ แก้แค่ CSS filter บรรทัดเดียว — เร็วที่สุด แต่แบบ 12 ต้องเขียน filter แยกสำหรับ hover/active
แบบ 14–15 = ใช้ตัวอักษรย่อ (P / L / S / C / O / U) แทนไอคอน
