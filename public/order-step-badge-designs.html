badge แยก 3 ขั้นตอน บนปุ่มเมนู Order ใน sidebar หน้า Sale Support — นับจากคอลัมน์จริง arrived_branch / customer_notified / delivered ในตาราง ss_orders ด้วยเกณฑ์เดียวกับตราประทับใน popup (stepDone: มีคำว่า “แล้ว” และไม่มี “ยังไม่”)

เส้นประแดงในทุกภาพ = ขอบ 150px ซึ่งเป็น min-width จริงของ .ss-sidebar — แบบไหนล้ำเส้น แปลว่าต้องขยาย sidebar

ข้อมูลจริงตอนนี้: ss_orders มี 5 รายการ · ค้างจริง ของถึงสาขา 0 · แจ้งลูกค้า 0 · ส่งมอบสินค้า 1 — น้อยเกินกว่าจะเทียบดีไซน์ได้ จึงใส่ช่องปรับเลขไว้ด้านล่าง ลองกด “ตัวอย่าง” หรือ “เลข 3 หลัก” เพื่อดูว่าแต่ละแบบรับเลขยาวได้แค่ไหน
ตำแหน่ง badge: ผมตีความว่า “อยู่ที่ ของถึงสาขา” = ให้ช่อง ของถึงสาขา เป็นตัวนำ/ตัวเด่นของกลุ่ม (มาก่อน หรือใหญ่กว่า) — ถ้าหมายถึงอย่างอื่น บอกได้ครับ แก้ให้
จำนวนที่ยังค้าง:
อ่านผลยังไง — ป้าย กว้าง 150px คือพอดี sidebar เดิม ไม่ต้องแก้อะไร · กว้าง 168px คือต้องขยาย min-width ของ .ss-sidebar · สูง +17px คือปุ่ม Order จะสูงกว่าปุ่มอื่น (เมนูเรียงไม่เท่ากัน)
ตัวเลขทั้งสองวัดจากของจริงบนหน้าจอตอน render ไม่ได้พิมพ์ไว้ล่วงหน้า — เปลี่ยนตัวเลขในช่องด้านบนแล้ววัดใหม่ทุกครั้ง
