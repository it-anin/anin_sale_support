แจ้งจัดซื้อ / แจ้งคลังสินค้า — ต้องบังคับเลือก

ฟอร์ม ➕ Add BackOrder หน้า SaleSupport — ตัวเลือกใหม่ที่ตัดสินว่าจะแจ้งเตือนรหัสจัดซื้อด้วยหรือไม่ (คลังสินค้าได้รับแจ้งเตือนเสมอไม่ว่าจะเลือกอะไร)

ป้าย "บังคับจริงไหม" มุมขวาการ์ด วัดจากโค้ดจริงในหน้านี้ — เช็คว่าค่าเริ่มต้นตอนโหลดหน้าเป็นค่าว่างไหม

ทำไมต้องบังคับ ไม่ใช่แค่ dropdown ปกติ
ฟิลด์อื่นในฟอร์มนี้ทุกตัวที่เป็น select จะ default เป็นตัวเลือกแรกเสมอ (เช่น ช่องทางติดต่อของ Order เป็น Tel. ตั้งแต่เปิดฟอร์ม) แต่ตัวเลือกนี้ เลือกผิดแล้วมีผลจริง — เลือก "คลังสินค้า" ทั้งที่ต้องสั่งของใหม่ = จัดซื้อไม่รู้ตัวว่าต้องสั่ง (ของขาดต่อ) · เลือก "จัดซื้อ" ทั้งที่ของมีอยู่แล้ว = จัดซื้อโดนแจ้งเตือนทั้งที่ไม่เกี่ยว (สแปม)
ทุกแบบด้านล่างจึงเริ่มต้นด้วยค่าว่าง และมีปุ่ม "บันทึก" จำลองที่บล็อกจริงถ้ายังไม่เลือก — ลองกดดูได้ทุกการ์ด
ป้ายบอกชนิดข้างชื่อแบบ — CSS เป็นหลัก ใช้ element เดิม (select/checkbox) แก้แค่ validation + สไตล์ · โครงใหม่ ต้องสร้างองค์ประกอบ interactive ใหม่ทั้งชุด (ปุ่มกำหนดเอง, สวิตช์ ฯลฯ)
วิธีทดสอบแต่ละการ์ด: กด "บันทึก" ทันทีโดยยังไม่เลือก → ต้องเห็น error สีแดง · เลือกอันใดอันหนึ่งแล้วกด "บันทึก" → ต้องเห็นข้อความสำเร็จสีเขียว · กด "รีเซ็ต" เพื่อกลับไปสถานะว่างแล้วลองใหม่
ไฟล์นี้เป็นแกลเลอรีเทียบดีไซน์เท่านั้น ยังไม่ได้ใส่เข้าแอป — ฟีเจอร์นี้ยังไม่มีอยู่จริงในฟอร์ม Add BackOrder ยังไม่มีแบบไหนถูกเลือกใช้จริง
